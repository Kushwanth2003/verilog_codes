# Verilog Code Repository

## Overview

This repository contains a collection of Verilog HDL programs covering fundamental to advanced digital design concepts. It is intended for students, beginners, and interview preparation in Digital Electronics, VLSI, RTL Design, and FPGA/ASIC design.

The repository includes well-structured Verilog implementations of commonly used digital circuits along with their corresponding testbenches (where applicable).

---

## Software Used

- ModelSim
- QuestaSim
- Xilinx ISE
- EDA Playground

---

## How to Simulate

1. Compile the Verilog source file.
2. Compile the corresponding testbench.
3. Run the simulation.
4. Observe the waveform and verify the output.
